## Gotchas that will cost you a day

**Apps Script redeploys.** Editing code does not update the live web app. Use
Deploy → Manage deployments → ✏️ → Version: **New version**. "New deployment"
mints a different `/exec` URL and every published site keeps hitting the old one.
This already happened once — hence the orphaned v1.0 deployment.

**Keep `Content-Type: text/plain`** in `lead-form.js`. Apps Script never answers
CORS preflight; `application/json` triggers one and loses leads silently while
showing the visitor a success message.

**Never share the Registry spreadsheet.** It holds every client.

**Never make Website-photos link-viewable.** The contractor has write access.
Publishing is per-file via `publishPhotos()` so a dropped contract can't go
public.

**Don't swap the photo URLs.** The manifest uses `=w600` / `=w1600` resized
variants, which are re-encoded and drop EXIF. Direct file URLs return the
original bytes — including GPS coordinates of customers' homes.

**Registry reads cache for 5 minutes.** Run `flushRegistryCache()` after edits.

**`netlify deploy` from the wrong folder** will try to publish that folder. Always
`cd` into `acp-backend` first and check `Deploy path:` in the output.
